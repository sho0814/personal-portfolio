# 자기소개 웹앱

HTML5, CSS3, Vanilla JavaScript로 만든 반응형 원페이지 포트폴리오입니다. 설치와 빌드 없이 실행할 수 있습니다.

## 로컬 실행

1. 프로젝트 폴더의 `index.html`을 브라우저로 엽니다.
2. HTTP로도 확인하려면 프로젝트 폴더에서 아래 명령을 실행하고 브라우저에서 `http://127.0.0.1:8000/`을 엽니다. 서버는 터미널에서 `Ctrl+C`로 종료합니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

## 테스트

- 메뉴의 Home, 소개, 프로젝트, 연락처, 방명록을 각각 눌러 해당 섹션으로 이동하는지 확인합니다. 브라우저 뒤로 가기로 메뉴 표시가 돌아오는지도 확인합니다.
- 각 프로젝트의 ‘상세 보기’를 눌러 기간, 역할, 기술, 결과를 펼치고 다시 접습니다. 키보드에서는 Tab으로 이동하고 Enter로 열거나 닫을 수 있습니다.
- 방명록의 이름과 메시지를 입력하고, 저장 미구현 안내와 비활성화된 등록 버튼을 확인합니다. 이번 주차에는 입력값을 전송하거나 저장하는 기능이 없습니다.
- 브라우저 개발자 도구에서 폭을 320px로 줄여 메뉴와 프로젝트 카드가 화면 안에 배치되는지 확인합니다.

## 내용 수정

- `index.html`에서 이름, 소개, 프로젝트, 연락처를 수정할 수 있습니다. 이름을 바꾸면 브라우저 탭에 표시되는 제목도 함께 수정합니다.
- `css/style.css`에서 색상과 레이아웃을, `js/app.js`에서 메뉴의 선택 상태 표시를 수정할 수 있습니다.
- `assets/`에 파비콘 등 정적 이미지를 둡니다. 이미지를 추가할 때는 `index.html`에서 상대 경로로 연결합니다.
